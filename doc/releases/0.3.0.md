# SSUI 0.3.0 发布说明

状态：发布准备，尚未创建候选 tag 或发布正式安装包。
变更范围：`0.2.0` 至版本准备 PR 的源码；功能基线为
`f4fbeb1352a80d548037b9b0404943b064f7742f`。

## 主要变化

- 工作流与界面：新增 Python 工作流编译、节点面板、通用配置和统一 UI
  状态管理；完善共享组件、画布图像输入、笔刷压力、WebGPU 与贝塞尔编辑。
- 图像与视频：加入 FLUX.2 Klein、Qwen 像素资源相关工作流，完善视频模型
  和 Windows ROCm 推理路径。
- 3D 与动作：扩展 Pixal3D、TRELLIS、HoloPart、P3-SAM、自动绑定及动作
  模型工作流，加入网格边界闭合及多种 CUDA、ROCm、Metal 适配。
  各模型仍有独立的硬件和依赖要求。
- 音频与文本：新增可选音乐、歌曲生成适配器，以及共用环境的文本生成、
  对话和 LoRA 工作流；加入开放生成协议与生成桥接接口。
- 模型管理：支持 ModelScope 仓库、搜索和下载，增加下载队列与校验；
  提供可选工作流量化及跨 worktree 共享模型、缓存和 Python 环境配置。
- 工程与发布：扩展前端、Rust、真实 IPC 和原生 UI 测试；完善离线
  Storybook、模块文档和依赖安全更新。桌面发布流程覆盖 Windows、macOS、
  Linux 的 x86_64 与 ARM64 六个原生目标，增加安装冒烟、架构审计、
  产物哈希和候选版晋升校验。

## 兼容性与升级说明

- 桌面应用版本统一为 0.3.0；独立组件、扩展构建器和 VS Code 插件保持
  各自版本，不随桌面版本批量升级。
- Linux 打包基线为 Ubuntu 24.04；Intel macOS 安装包最低声明为 macOS 14。
  其他最低系统要求须经目标系统验收，不以 CI runner 版本替代支持承诺。
- Windows ARM64 使用原生 CPU 依赖；Intel macOS 使用专用 CPU PyTorch
  wheel。平台可安装不代表所有 GPU 模型在该平台可运行。
- 可选模型可能需要额外依赖、源码工具及单独下载的权重；权重不包含在
  桌面安装包中。模型及适配器的商业使用权限应分别核查，不能由 SSUI
  的软件许可证推定。参见 [Audio](../../extensions/Audio/README.md)、
  [文本生成](../TextGeneration.md) 和 [动作模型](../MotionModels.md)。
- 不宣称安装包已签名或公证。升级前建议备份项目、工作流和本地配置，
  按当前平台依赖锁安装运行环境，并验证现有工作流。

## 发布验收清单

以下项目在候选提交上完成后记录结果，不能复用其他 SHA 的成功结果作为
本版本已通过的证明。完整操作规则见 [发布流程](../Release.md)。

- [ ] 版本准备 PR 合入 dev，记录最终源码 SHA。
- [ ] 候选 SHA 的 CI 成功，完成 `SSUI_RUN_MODEL_TESTS=1 yarn test` 真模型
  回归并记录硬件、环境、通过和跳过项。
- [ ] 创建不可变 `v0.3.0` tag 与 GitHub Pre-release。
- [ ] 六平台原生构建、运行时探针、架构审计和安装冒烟全部通过。
- [ ] 候选版包含六平台安装包、`release-manifest.json` 与 `SHA256SUMS`。
- [ ] promote PR 以 merge commit 合入 main，保留候选提交祖先关系。
- [ ] 从 main 执行 Promote release，验证原始产物并晋升正式版。
- [ ] 合并开发线同步 PR，记录最终 Release 和验证证据链接。

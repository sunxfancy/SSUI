# Canvas 图片输入

在 functional_ui 的 Image 参数中选择 `CanvasInput` 页签：

1. 选择“临时画布”，或从项目内的 `.canvas` 文件列表选择已有画布。
2. 点击“放大画布 / 编辑输入”，打开覆盖整个窗口的 Image 扩展编辑器。
3. 用画笔绘制，或移动已有图片。点击“用作图片输入”将当前画布区域的内容导出为 PNG，上传至项目 `input` 目录；工作流通过现有 `{ function: 'ssui.base.Image.load', params: { path: 文件路径 } }` 接口读取。
4. 取消不会替换已经确认的输入。重新打开保留上次确认的图片；未确认的修改会丢弃。

需要安装并启用 Image 扩展。全屏为应用窗口内覆盖层。

在普通 Canvas 文件编辑器中点击“保存画布”，保存目标区域的合成快照。文件格式为 `{ "version": 1, "image": "data:image/png;base64,...", "settings": { "unbounded": false, "width": 512, "height": 512, "margin": 32 } }`。再次打开可继续绘制，但图层会合并。空 `.canvas` 文件视为空白画布；不支持的非空格式会报错。作为输入编辑已有文件时不会覆盖原文件。

## 画布尺寸

编辑器底部可设置宽、高（默认 512×512），固定模式按目标框区域导出。

勾选“无边界”后，按可见绘图的实际非透明像素范围计算导出区域（包含旋转图片、笔画，排除网格、选框及擦除后的透明部分）。在四边各加 Margin（默认 32 像素），宽、高分别向上取整到 64 的倍数，额外留白居中分配，不缩放绘图。例如内容 501×700、Margin=32，导出 576×768。空画布最小为 64×64，也会考虑 Margin。

尺寸设置会随 `.canvas` 快照保存，并在关闭、重新打开已确认的图片输入时恢复。旧版无 settings 的快照按图片原始尺寸打开。
